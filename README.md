# Animo - Animation Tool

A standalone, lightweight animation tool built in Unity, designed to bridge the gap between real-time IK animation and professional Blender workflows.

## 📥 Download
Go to the **[Releases](../../releases/latest)** tab on the right side of this page and download the latest `Animo_v0.1_Windows.zip`. 

## ✨ Features
* **Custom Timeline:** Keyframe your animations with DOTween easing curves, ghost frames, and motion paths.
* **IK/FK Rigging:** Drag and pose characters easily with automatic IK constraints.
* **Prop Engine:** Spawn custom GLB models, scale them, and attach them to humanoid bones (e.g., swords to hands).
* **Blender Bridge:** Export your animation directly to Blender, automatically clean up the baked keyframes, and export a production-ready Skeleton FBX.

## 🚀 Quick Start
1. Extract the ZIP file and run `Animo.exe`.
2. Press `H` or click the Help button to view the Hotkey Cheat Sheet.
3. To set up the Blender Bridge, open the tool and click **Get Blender Add-on**.

## ⚠️ Important Notes
* This tool is distributed as a **free binary**. The source code is not publicly available.
* **Do not** use the Blender Add-on for commercial redistribution.
* The tool relies on a specific humanoid rig structure.
